CHƯƠNG 2: CÔNG NGHỆ SỬ DỤNG & QUY CHUẨN THIẾT KẾ
================================================================================

2.1. Nền tảng cốt lõi: React 18 & Vite:
- React 18: Thư viện giao diện hàng đầu thế giới với kiến trúc Component-driven, 
  hỗ trợ đầy đủ các React Hooks hiện đại (useState, useEffect, useMemo).
- Vite 5: Công cụ build tool thế hệ mới thay thế Create-React-App truyền thống, 
  khởi động máy chủ phát triển gần như tức thì (Hot Module Replacement) nhờ tận 
  dụng Native ES Modules và trình biên dịch esbuild bằng Go.

2.2. Styling & Icon:
- Tailwind CSS 3: Utility-first CSS framework giúp xây dựng giao diện nhanh 
  chóng, đồng bộ bảng màu và hoàn toàn tương thích trên mọi kích thước màn hình 
  (Responsive Design).
- Lucide React: Bộ thư viện icon vector sắc nét, tải theo dạng cây (tree-shaking) 
  để tối ưu dung lượng gói bundle.

2.3. Quy chuẩn thiết kế Canva Presentation Standard (Strict Inversion Rule):
Nhằm tạo nên một giao diện trang nhã, đậm chất học thuật công nghệ và chống mỏi 
mắt trên máy chiếu/thiết bị điện tử, ứng dụng tuân thủ nghiêm ngặt hệ thống thiết 
kế chuẩn Canva:
- Nền Canvas (Canvas Background): Mã màu #f7f7f7 (Xám trắng hiện đại).
- Màu thương hiệu (Royal Blue): Mã màu #2657c1 (Điểm nhấn, header, nút chính).
- Thẻ Trắng (Card White - #ffffff): Tiêu đề màu Xanh Royal #2657c1, nội dung 
  chữ thân bài màu Deep Slate #1e293b, đường viền thanh mảnh #e2e8f0.
- Thẻ Xanh (Card Blue - #2657c1): BẮT BUỘC áp dụng quy tắc đảo màu tương phản 
  tuyệt đối (Strict Inversion Rule) - tiêu đề và nội dung chữ mang màu Trắng tinh 
  khiết (#ffffff), huy hiệu tag màu xanh nhạt #ebf2ff.
- Khối Code (Code Blocks): Nền tối phong cách terminal #0f172a, sử dụng font chữ 
  đặc trưng Consolas / JetBrains Mono.
- Typography: Font chữ Montserrat với khả năng hiển thị tiếng Việt hoàn hảo, 
  không bao giờ bị lỗi font chân chữ.

BTTH1-React-Blog/

├── package.json                # Định nghĩa dependencies (React 18, Tailwind, Lucide)
├── tailwind.config.js          # Khai báo Design Tokens chuẩn màu Canva (#2657c1, #f7f7f7)

    ├── main.jsx                # Điểm khởi đầu mount React DOM vào root

        ├── BlogCard.jsx        # Thẻ hiển thị bài viết đan xen Xanh/Trắng (Strict Inversion)
        ├── PostDetailModal.jsx # Giao diện đọc bài chi tiết, syntax highlight, bình luận
        ├── CreatePostModal.jsx # Form soạn bài viết mới có kiểm tra dữ liệu và lưu LocalStorage
        └── Footer.jsx          # Chân trang, bản quyền sinh viên PTIT, nút reset dữ liệu

3.2. Luồng dữ liệu (Data Flow):
Dữ liệu bài viết khởi tạo từ `mockPosts.js` -> nạp vào State `posts` tại `App.jsx` 
với cơ chế đọc kiểm tra `localStorage`. Khi người dùng thực hiện:
- Thêm bài viết mới -> Gọi `handleCreatePost` -> Cập nhật State `posts` -> Lưu `localStorage`.
- Thả tim (Like) -> Gọi `handleToggleLike` -> Cập nhật trực tiếp số đếm.
- Tìm kiếm hoặc lọc danh mục -> Kích hoạt `useMemo` tính toán mảng `filteredPosts` 
  mà không cần render lại toàn bộ component cha.

Sử dụng các React Hooks then chốt:
- `useState`: Quản lý danh sách bài viết `posts`, từ khóa tìm kiếm `searchQuery`, 
  chuyên mục kích hoạt `activeCategory`, chế độ tối `isDarkMode`, bài viết được chọn `selectedPost`, 
  danh sách ID bài đã lưu `bookmarkedIds`.

  dữ liệu bài viết vào `localStorage`.
- `useMemo`: Tối ưu hiệu năng bộ lọc tìm kiếm `filteredPosts` và tính toán tổng số lượt yêu thích, 
  ngăn chặn các re-render lãng phí khi state khác thay đổi.

quản lý mã nguồn bằng Git/GitHub, đồng thời rèn luyện kỹ năng thiết kế UI/UX theo 
tiêu chuẩn tương phản cao. Đây là nền tảng quan trọng để sinh viên tiếp tục hoàn 
thành xuất sắc Bài tập Thực hành 2 và Bài tập lớn môn Lập trình Web.
